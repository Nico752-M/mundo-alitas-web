# Mundo Alitas — sitio conceptual v2

Sitio estático responsive construido con HTML, CSS y JavaScript. La experiencia está inspirada en la secuencia visual del video de Busy Bee Honey: hero tipográfico, bandas marquee, secciones narrativas con fotografía, carrusel horizontal de productos, manifiesto, bloque de pedido y cierre de marca.

## Cómo abrir
1. Descomprime la carpeta.
2. Abre `index.html` en Chrome, Edge u Opera.
3. Para desarrollo local, puedes usar la extensión Live Server de VS Code.

GSAP y ScrollTrigger se cargan desde CDN; se requiere conexión a internet para esas animaciones y Google Fonts. El sitio mantiene una presentación estática funcional si no cargan.

## Antes de publicar
- Reemplazar `570000000000` en `script.js` por el número de WhatsApp real en formato internacional, sin `+` ni espacios.
- Confirmar los sabores, nombres, ingredientes, precios y disponibilidad. El menú actual es conceptual.
- Añadir dirección, horarios, redes y enlaces reales.
- Sustituir fotografías de referencia por fotografías propias del restaurante.

## Paleta
- Negro: `#080806`
- Amarillo: `#ffd52e`
- Crema: `#f6edcf` (solo como tono de apoyo para texto y contraste; el protagonismo cromático es negro y amarillo).

No se utilizan frameworks de UI ni un proceso de compilación.
